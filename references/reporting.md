# 复盘与掌握度

用中文简短复盘，日语原句与改法保留日语。顺序：任务结果 → 具体成功表达 → 目标状态 → 必要纠正 → 下次最多三项 → 一个 2–5 分钟迁移任务。

只引用当前对话中真实出现的用户措辞；缺少原文时标记「意图摘要」，不伪造引号里的句子。可接受的表达保留为 `keep`，需要改的标记 `repair`，仅更自然的选项标记 `alternative`。可为建议句单独提供假名 `natural_reading`，不得改写原句证据。

## 目标状态

| status | 标准 |
|---|---|
| mastered | 独立且合语境地正确表达；换情境再次使用可增强证据。一次成功只说明本次表现，不承诺长期掌握。 |
| developing | 在中文意图提示后正确表达，或做了轻量自我修正。 |
| needs_review | 依赖日语关键词、完整示范，反复修正，或有公平机会却没有完成。 |
| not_observed | 没有公平机会检验；不惩罚，不计为失败。 |

支持等级独立保存：`independent`、`intent_hint`、`keyword_hint`、`model`、`none`。`none` 用于未观察；模仿后不能立即宣称独立掌握。一个词已被教练展示过不是用户表现。

以助词、动词／形容词活用、数量读法、语体和措辞为可能关注点，但只报告有证据的问题。不要把常见相槌、自然省略或语义等价表达都纠成教科书句。

评分可省略；需要时只用透明的任务完成、清晰度、表达范围、互动四个 1–5 分维度。不做 JLPT 定级，不编造「口语 N2」结论。无原声时 pronunciation.status = not_observed 且 notes = []。

结束后按 [数据规范](workbench-data.md) 归档。读取历史复练时先取最近一次的 focus_next 和 needs_review 目标，提出不同情境的问题；不把所有历史重读或粘贴给用户。
